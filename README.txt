# PetCare — Blue Theme Starter

A cute, colourful, blue-themed semi-functional pet-care website built with HTML, CSS and JavaScript.

## Run it
1. Extract the ZIP file.
2. Open the `petcare_blue` folder.
3. Double-click `index.html` to open it in a browser.

For a smoother development workflow, open the folder in Visual Studio Code and use the Live Server extension.

## Working features
- Dashboard summary
- Add and remove pet profiles
- Add and remove health records
- Add and remove feeding entries
- Add and remove vet appointments
- Pet-care tips section
- LocalStorage saves data in the current browser

## Notes
- This is a frontend college-project prototype. It has no server, login system, or shared database.
- Data is stored in the browser on the device where it is entered.
- The default sample pet is Toffee; you can remove it and add your own pet.
- Dates in the demo records can be edited or removed.
